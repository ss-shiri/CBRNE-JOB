# CBRNE Job Search OSINT Toolkit

This repository provides an OSINT-based toolkit for discovering job openings related to
Chemical, Biological, Radiological, Nuclear, and Explosives (CBRNE) fields.

## Features
- Comprehensive keyword lists for CBRNE job discovery
- Modular crawlers and scrapers for multiple job platforms
- Automated filtering of relevant job postings
- Export of raw and cleaned datasets
- Easy-to-extend architecture for new sources
